## ❓ 常见问题

### 🔧 安装相关

**Q: 安装时提示病毒怎么办？**

A: 这是误报，Clash Verge 是开源软件，可以：

1. 添加到杀毒软件白名单
2. 临时关闭实时保护进行安装
3. 从官方 GitHub 下载确保文件完整性

**Q: 安装后无法启动？**

A: 请检查：

1. 系统是否满足最低要求
2. 是否有其他代理软件冲突
3. 尝试以管理员身份运行
4. 重新下载安装包

### 🌐 使用相关

**Q: 如何导入配置？**

A: 支持多种导入方式：

1. **URL 订阅**：直接粘贴订阅链接
2. **本地文件**：选择本地 .yaml 配置文件
3. **剪贴板导入**：从剪贴板直接导入配置

**Q: 配置更新失败怎么办？**

A: 尝试以下解决方案：

1. 检查网络连接是否正常
2. 验证订阅链接是否有效
3. 尝试手动更新配置
4. 重新导入配置文件
