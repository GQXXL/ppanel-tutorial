2. **允许安装**
   - 设置 → 安全 → 开启"未知来源"
   - 或在安装时选择"允许此次安装"

3. **完成安装**
   - 点击 APK 文件开始安装
   - 按照提示完成安装过程

## 🚀 使用教程

### 📋 配置步骤

#### 🔥 步骤总览

1. **📱 启动应用** - 打开 Clash Meta for Android
2. **⚙️ 导入配置** - 添加订阅链接或配置文件
3. **🌐 选择节点** - 从节点列表中选择服务器
4. **🚀 开启代理** - 启动代理服务
5. **✅ 验证连接** - 确认代理功能正常

## 🎛️ 高级功能

### 📊 规则管理

- **域名规则**：基于域名的智能分流
- **IP 规则**：基于 IP 地址的精准分流
- **GeoIP 规则**：基于地理位置的自动分流
- **自定义规则**：支持用户自定义分流规则

### 🔄 策略组配置

- **自动选择**：根据延迟自动选择最优节点
- **负载均衡**：流量在多个节点间均衡分配
- **故障转移**：节点失效时自动切换备用节点
- **手动选择**：用户手动指定使用的节点

### 📈 监控和统计

- **实时流量**：显示当前上传/下载速度
- **连接信息**：查看活跃连接详情
- **日志记录**：详细的运行日志信息
- **规则匹配**：显示规则命中情况

## ❓ 常见问题

### 🔧 技术支持

**Q: 无法导入配置？**

A: 请检查：

- 订阅链接是否正确
- 网络连接是否正常
- 配置格式是否兼容

**Q: 连接后无法上网？**

A: 排查建议：

- 检查节点是否可用
- 确认 VPN 权限已授予
- 尝试切换不同节点

**Q: 应用崩溃或卡顿？**

A: 解决方案：

- 重启应用或设备
- 清除应用缓存数据
- 检查系统资源占用
